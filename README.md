# Luna Bistro — Responsive Restaurant Template

Premium, mobile-first template for a fictional Indian restaurant. Built with semantic HTML, CSS, and vanilla JavaScript. Easy to customize for another business.

Quick start

1. Open `index.html` in a browser, or serve locally:
   - `python -m http.server 8000` and open `http://localhost:8000`
2. Edit content and replace images in the project folder.

To push to GitHub:

1. Create a new empty repo on GitHub.
2. Run:
   ```powershell
   git remote add origin https://github.com/<your>/<repo>.git
   git push -u origin main
   ```
